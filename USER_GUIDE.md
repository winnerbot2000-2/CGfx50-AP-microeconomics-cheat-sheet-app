# CG Micro User Guide

## Home Screen

The add-in opens to a home menu with:

- Units
- Concepts
- Vocabulary
- Graphs
- Formulas
- Structures
- Quick Review
- Exam Cram
- Reference
- Recent
- About / Help

## Controls

- `UP` / `DOWN`: move through lists or scroll text
- `LEFT` / `RIGHT`: page through long text
- `EXE`: open the selected item
- `EXIT`: go back
- `F1` / `F2`: context actions on some pages
- `F3` / `F4` / `F5` / `F6`: graph-atlas actions on graph visual pages

## Best Ways To Study

### Units

Open a unit to read:

- overview
- key ideas
- key vocabulary
- common mistakes
- exam reminders

From a unit page:

- `F1` opens the topics for that unit
- `F2` opens the vocabulary for that unit

### Vocabulary

Choose either:

- `By Unit`
- `A-Z Master List`
- `By Category`

Each term page shows:

- short definition
- full explanation
- unit / topic anchor
- category
- what the term is used for
- question type cues
- either an exact graph location or a real-world example with graph effect
- visual understanding cue
- related formulas and terms
- common confusion
- AP exam tip

When a term is graph-linked, `F1` opens the graph with the matching element highlighted.
Use `LEFT` / `RIGHT` on a term page to switch between summary, deep explanation, mini graph, and links.
On the vocab visual page:

- `F1` or `EXE` opens the full graph with the term highlighted
- `F2` opens the first related formula
- `F6` opens a related term

### Concepts

Use `Concepts` for larger AP ideas such as equilibrium, elasticity, monopoly pricing, monopsony, and externalities.

Each concept page includes:

- a short definition page
- a deep explanation page
- a visual page with a native mini graph
- a links page with related terms and formulas

Concept controls:

- `LEFT` / `RIGHT` switches between concept pages
- `F1` opens the linked full graph
- `F2` opens the first related vocabulary term
- `F6` opens the first related formula

Mini graphs are intentionally simplified:

- smaller drawing area
- reduced labels
- focus on the key curve, point, or shaded region
- same highlight logic as the full graph system

### Graphs

Each graph entry has:

- a diagram page
- labels page
- shifts page
- reading guide
- common questions
- common mistakes

On the graph visual page:

- `F1` toggles labels
- `F2` cycles the focused curve, point, or shaded area
- `F3` toggles shaded-area mode
- `F4` toggles shift / before-after mode
- `F5` toggles the explanation panel
- `EXE` opens the focused vocabulary term
- `F6` opens the focused related formula
- `LEFT` / `RIGHT` switches between the visual and the explanation tabs

When a vocab term has graph metadata, `F1` from the term page opens the graph with that term focused when the graph atlas has a matching selectable element.

### Formulas

Each formula card shows:

- the formula
- variable meanings
- an AP-focused tip

If the formula supports a quick calculator, press `F1`.

Included helpers:

- price elasticity of demand
- price elasticity of supply
- cross-price elasticity
- income elasticity
- midpoint elasticity
- total revenue
- marginal revenue basics
- total cost
- economic profit
- accounting vs economic profit
- average costs
- marginal cost
- tax revenue
- deadweight loss
- marginal revenue product

Use this section for fast exam review:

### Reference

Use this section for cheat sheets:

### Exam Cram

Use this section for compressed high-yield review:

- terms
- graphs
- formulas
- policy reminders
- market structure facts

### Recent

Use `Recent` to jump back to the last unit, term, graph, formula, or review page you opened.

## Practical Study Flow

1. Start with `Exam Cram` or `Quick Review` when you need a fast pass.
2. Use `Units` for focused content review.
3. Jump to `Vocabulary` when a term shows up in a graph or FRQ prompt.
4. Use `Graphs` when a concept is graph-heavy and tab through labels, shifts, and mistakes.
5. Use `Formulas` and `F1` helpers for numeric practice.
6. Use `Recent` to bounce between the pages you are actively studying.
